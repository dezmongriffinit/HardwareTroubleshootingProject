## Scenario 1: Printer Not Printing

### Problem

A user reports that their printer is not printing documents.

### Troubleshooting Steps

1. Checked printer power.
2. Verified cable and network connections.
3. Checked printer queue.
4. Restarted printer.
5. Printed test page.

### Resolution

A stuck print job was cleared from the queue and printing functionality was restored.

---

## Scenario 2: Monitor Not Displaying Image

### Problem

A user reports a blank monitor screen.

### Troubleshooting Steps

1. Checked monitor power.
2. Verified video cable connections.
3. Tested monitor with another computer.
4. Tested alternate display cable.
5. Verified display settings.

### Resolution

A loose HDMI cable was identified and secured.

---

## Scenario 3: Keyboard Not Responding

### Problem

A user reports their keyboard is not functioning.

### Troubleshooting Steps

1. Reconnected keyboard.
2. Tested different USB port.
3. Updated drivers.
4. Tested alternate keyboard.

### Resolution

The original USB port was defective. Moving the keyboard to a working port resolved the issue.
